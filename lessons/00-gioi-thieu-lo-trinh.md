# Bài 00 — Giới thiệu & lộ trình

## Mục tiêu

Sau seri này bạn có thể:

- Đọc và viết Python **chuẩn chỉnh** từ script nhỏ tới module có tổ chức.
- Làm **CLI, file/JSON, API đơn giản**, và hiểu **cách đọc tài liệu/skill AI** để tự động hóa.

## Bạn cần gì

- Máy tính với Python 3.11 trở lên.
- Trình soạn thảo (VS Code, Cursor, v.v.) và terminal.

## Kiểm tra Python

```bash
python --version
```

Hoặc trên một số hệ thống:

```bash
py --version
```

## Thói quen tốt

- Gõ code tay, không chỉ copy.
- Mỗi khái niệm mới: **một ví dụ nhỏ** rồi mới ghép vào bài lớn.
- Khi lỗi: đọc **traceback** từ dưới lên; dòng cuối thường nói rõ lỗi gì.
